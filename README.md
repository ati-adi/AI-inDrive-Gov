# SubsidyAI — AI-советник для субсидий животноводства

AI-система скоринга заявок на субсидии в животноводстве Казахстана. Помогает сотрудникам МИО (местных исполнительных органов) быстрее и обоснованнее принимать решения по заявкам из ГИСС.

## Проблема

Сотрудник МИО получает сотни заявок на субсидии. На каждую — 2 рабочих дня. Проверка вручную: сверить документы, оценить фермера, учесть региональные нормы. Решение субъективное, зависит от опыта конкретного человека.

## Решение

AI-советник анализирует заявку по 6 компонентам и даёт рекомендацию: одобрить или отклонить. Объясняет почему. Чиновник видит скор, reasoning и чат с AI — и принимает финальное решение сам.

## Как работает

```
Excel из ГИСС → Pipeline (XGBoost + правила + аномалии) → Скор 0-100 → Дашборд
                                                                          ↓
                                                         Чиновник решает → БД
                                                                          ↓
                                                         Batch переобучение модели
```

### Компоненты скоринга

| Компонент | Что оценивает | Вес |
|-----------|--------------|-----|
| Прогноз по истории | Как решались похожие заявки в прошлом | ~83% |
| Надёжность | Стаж фермера, динамика стада, падёж | ~15% |
| Регион | Статистика одобрений в районе | ~2% |
| Аномалии | Отклонение от типичных заявок | <1% |
| Масштаб | Размер хозяйства | <1% |
| Правила | Соответствие нормативам из PDF | <1% |

### Нормативная база

- Правила субсидирования (приказ МСХ РК №108 от 15.03.2019, ред. №428 от 18.11.2025)
- Нормы естественной убыли (падежа) сельскохозяйственных животных
- Предельно допустимые нормы нагрузки на пастбища по областям

## Стек

- **ML**: XGBoost, Isolation Forest, DBSCAN, scikit-learn, SHAP
- **Backend**: Python, FastAPI, SQLAlchemy (PostgreSQL/SQLite)
- **AI**: K2Think API (MBZUAI-IFM/K2-Think-v2) — объяснения на русском
- **Frontend**: HTML/CSS/JS (single page, dark theme)

## Установка и запуск

```bash
# Зависимости
pip install pandas numpy xgboost scikit-learn shap openpyxl fastapi uvicorn requests sqlalchemy psycopg2-binary python-multipart

# Обучение модели (первый запуск, ~47 сек)
cd src && python pipeline.py with_isj

# Запуск API
cd ../api && python -m uvicorn main:app --reload --port 8000

# Открыть http://localhost:8000
```

### PostgreSQL (опционально)

```bash
export DATABASE_URL=postgresql://user:pass@localhost:5432/subsidy
```

Без этой переменной — работает на SQLite (файл `data/subsidy.db`).

## Структура проекта

```
├── src/
│   ├── data_loader.py          # Чтение и очистка Excel
│   ├── synthetic_isj.py        # Синтетические профили фермеров
│   ├── feature_engineering.py  # 35 фичей для ML
│   ├── xgboost_model.py        # XGBoost + SHAP
│   ├── anomaly_detector.py     # Isolation Forest + DBSCAN
│   ├── rule_checker.py         # 11 правил из PDF
│   ├── scorer.py               # Калибровка весов, финальный скор
│   ├── llm_explainer.py        # K2Think API, чат
│   ├── pipeline.py             # Оркестратор
│   └── database.py             # SQLAlchemy модели
├── api/
│   └── main.py                 # FastAPI (9 эндпоинтов)
├── frontend/
│   └── index.html              # Веб-интерфейс
└── data/
    ├── raw/                    # Исходный Excel
    └── processed/              # Результаты pipeline
```

## API эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Фронтенд |
| GET | `/applications` | Список заявок (фильтры, пагинация) |
| GET | `/applications/{id}` | Карточка заявки со скором |
| GET | `/applications/{id}/explain` | Одноразовое AI-объяснение |
| POST | `/applications/{id}/chat` | Чат с AI про заявку |
| POST | `/applications/{id}/decision` | Решение чиновника → БД |
| POST | `/score` | Скор одной новой заявки |
| POST | `/upload` | Загрузка Excel → pipeline |
| GET | `/stats` | Статистика |

## Метрики

- **XGBoost AUC**: 0.97 (с ИСЖ), 0.82 (без ИСЖ)
- **Калиброванный AUC**: 0.98
- **Pipeline**: ~47 сек на 36K заявок
- **Правила**: 11 проверок из PDF, ловят 24.8% отклонённых по пастбищам
